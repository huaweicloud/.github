## 关于我们 / About Us

HUAWEI CLOUD 组织托管华为云面向开发者的开源项目，涵盖 **SDK / 工具 / 服务集成 / 示例** 等多个领域，帮助开发者快速接入华为云能力。
*The HUAWEI CLOUD organization hosts open source projects for developers across **SDK / Tools / Service Integration / Samples**, helping you quickly connect to Huawei Cloud capabilities.*

## 快速开始 / Quick Start

在 [Issues](https://github.com/huaweicloud/repository-requests/issues) 中提交申请，即可在组织下创建新的开源仓库。
*Submit a request in [Issues](https://github.com/huaweicloud/repository-requests/issues) to create a new open source repository under the organization.*

1. 打开 [新建仓库申请](https://github.com/huaweicloud/repository-requests/issues/new/choose) / *Open [Create Repository Request](https://github.com/huaweicloud/repository-requests/issues/new/choose)*
2. 填写仓库信息（类型、名称、许可证、负责人等）/ *Fill in repo info (type, name, license, owners, etc.)*
3. 审批通过后自动完成初始化（CI / CODEOWNERS / Issue 模板等）/ *Auto-initialized after approval (CI / CODEOWNERS / Issue templates, etc.)*
