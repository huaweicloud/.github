# HUAWEI CLOUD

华为云官方开源组织 · 开放华为云技术能力，与全球开发者共建云生态。

---

## 关于我们

HUAWEI CLOUD 组织托管华为云面向开发者的开源项目，涵盖 **SDK / 工具 / 服务集成 / 示例** 等多个领域，帮助开发者快速接入华为云能力。

## 热门项目

| 项目 | 领域 | 说明 |
|------|------|------|
| [terraform-provider-huaweicloud](https://github.com/huaweicloud/terraform-provider-huaweicloud) | IaC | 华为云 Terraform Provider，用代码管理云资源 |
| [huaweicloud-sdk-go](https://github.com/huaweicloud/huaweicloud-sdk-go) | SDK | Go 语言华为云 SDK |
| [huaweicloud-sdk-python](https://github.com/huaweicloud/huaweicloud-sdk-python) | SDK | Python 语言华为云 SDK |
| [huaweicloud-sdk-java](https://github.com/huaweicloud/huaweicloud-sdk-java) | SDK | Java 语言华为云 SDK |
| [huaweicloud-obs-obsutil](https://github.com/huaweicloud/huaweicloud-obs-obsutil) | 工具 | OBS 命令行工具 |
| [spring-cloud-huawei](https://github.com/huaweicloud/spring-cloud-huawei) | 集成 | Spring Cloud 华为云集成 |

## 快速开始

在 [Issues](https://github.com/huaweicloud/repository-requests/issues) 中提交申请，即可在组织下创建新的开源仓库：

1. 打开 [新建仓库申请](https://github.com/huaweicloud/repository-requests/issues/new/choose)
2. 填写仓库信息（类型、名称、许可证、负责人等）
3. 审批通过后自动完成初始化（CI / CODEOWNERS / Issue 模板等）
